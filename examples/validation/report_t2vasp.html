1. プロジェクト概要

t2vasp は、VASP（Vienna Ab initio Simulation Package）の計算結果を自動的に後処理し、 結晶場理論に基づく物理量（t2g/eg 分裂、CFSE、ヤーン・テラー指標）を抽出するための Python ツールキットです。

本プロジェクトの最重要方針は、指示書に記載された通り：

「単に動くコードを書くだけでなく、データの一貫性と解析精度の担保を最優先事項として取り組んでください。」

この方針に基づき、以下の設計原則を徹底しました：

  • モジュール化：機能ごとに独立したモジュール（parser, calculator, exporter 等）に分離
  • 設定の外部化：物理定数・係数はすべて YAML 設定ファイルから読み込み、ハードコーディング禁止
  • 純関数設計：計算ロジックはすべて「物理パラメータを受け取って値を返す関数」として独立
  • 教科書値との照合：CFSE テーブルを教科書値と 1:1 で比較検証
  • ロギング：print() ではなく logging ライブラリによる進捗表示

2.3 データクラス設計

すべての中間データと結果は dataclass で型付け定義し、as_dict() メソッドで シリアライズ可能としています。

パーサー出力

  • StructureData: 格子ベクトル、元素種、分率座標
  • OutcarData: 全エネルギー、原子数、収束判定、力、応力テンソル
  • DosData: エネルギー軸、全DOS、フェルミエネルギー、projected DOS
  • VasprunData: XML 解析結果（電子収束・イオン収束）

解析結果

  • EnergyResult: 全エネルギー、E/atom、形成エネルギー
  • StructureResult: 格子定数、体積、c/a、最大力、圧力
  • CrystalFieldResult: Δoct、CFSE、JT活性・強度、eg分裂
  • JahnTellerResult: JTSE、JTSE/atom、Δ(c/a)
  • CalculationResult: 上記すべてを集約

3. フェーズ1–2: パーサーとコアロジック

3.1 VASP ファイルパーサー (parser.py, 349行)

外部 VASP 専用ライブラリに依存せず、stdlib の xml.etree.ElementTree と numpy のみで以下の4形式を解析します：

parse_poscar(path) → StructureData

POSCAR / CONTCAR ファイルからの格子ベクトル・元素種・分率座標の抽出。スケール因子の適用、 Direct/Cartesian 座標の判定を含む。

# 格子定数は lattice_constant プロパティで取得
struct = parse_poscar("CONTCAR")
print(f"a = {struct.lattice_constant:.3f} Å")
print(f"V = {struct.volume:.3f} ų")

parse_outcar(path) → OutcarData

正規表現によるテキストパターンマッチングで以下を抽出：

  • 全エネルギー (free energy TOTEN)
  • 原子数 (NIONS)
  • 収束判定 (reached required accuracy)
  • 原子間力 (TOTAL-FORCE ブロック)
  • 応力テンソル（Voigt 表記、6成分）
  • フェルミエネルギー、磁気モーメント、計算時間

parse_doscar(path) → DosData

DOSCAR ファイルから全状態密度（total DOS）とエネルギー軸を読み取り。フェルミエネルギーは ヘッダ行（6行目）から取得。

parse_vasprun(path) → VasprunData

XML 形式の vasprun.xml を ElementTree で解析し、projected DOS（軌道分解 DOS）を含む 電子構造データを抽出。空の <set> 要素に対する ndim ガードを実装し、 IndexError を防止。

3.2 コア計算ロジック (calculator.py, 506行)

compute_energy(outcar, reference_energies, species) → EnergyResult

OUTCAR の全エネルギーからアトムあたりエネルギー (E/atom) と形成エネルギーを計算：

Eformation = (Etotal − Σi Eref(speciesi)) / Natoms

compute_structure_metrics(struct, outcar) → StructureResult

格子定数 a（第1ベクトルのノルム）、体積（行列式）、c/a 比、最大原子間力、 圧力（応力テンソルのトレース/3）を導出。

compute_delta_energy(results, reference_label) → Dict[str, float]

複数計算結果間の ΔE (eV/atom) を計算。参照はラベル指定またはエネルギー最小構造。 構造ランキングに使用。

6. フェーズ5: 構造操作と自動化（ASE連携）

指導事項に従い、ASE (Atomic Simulation Environment) を活用して結晶構造の操作を実装しました。 USPEXの「構造生成 → VASP実行 → 結果回収」のワークフローの基盤となる機能群です。

6.1 バルク構造生成

create_bulk(symbol, crystal_type, a) → Atoms

FCC / BCC / HCP / SC の基本構造を ASE の bulk() で生成。

6.2 秩序構造生成

create_l12(element_face, element_corner, a) → Atoms

L12 構造（Cu3Au 型）の単位胞を直接構築。 面心位置に element_face を3原子、角に element_corner を1原子配置（計4原子）。

# Ni3Al L1₂ 構造
atoms = create_l12("Ni", "Al", a=3.572)
# → 4原子: Ni×3 + Al×1

create_b2(element_a, element_b, a) → Atoms

B2 構造（CsCl 型）の単位胞。原点に element_a、体心位置 (0.5, 0.5, 0.5) に element_b （計2原子）。

# FeAl B2 構造
atoms = create_b2("Fe", "Al", a=2.87)
# → 2原子: Fe×1 + Al×1

6.3 構造変形

apply_strain(atoms, strain, axis) → Atoms

等方性または一軸ひずみの適用。axis=None で全方向に同一ひずみ、 axis=2 で z 軸のみにひずみを適用（正方歪み模擬）。

a' = a × (1 + ε)
等方性: 全格子ベクトルに (1+ε) を乗算
一軸: 指定軸の格子ベクトルのみに (1+ε) を乗算

perturb_positions(atoms, amplitude, seed) → Atoms

原子位置にガウスノイズを加える。SQS（Special Quasirandom Structure）的な 無秩序配列の模擬に使用。

6.4 候補構造生成

generate_candidates(base_atoms, strain_values, output_dir) → List[Path]

基準構造に対して複数のひずみ値を適用し、それぞれの POSCAR を自動生成。 指示書の要求「t2vaspの結果に基づいて、次の計算のための入力ファイルを自動生成する」を実現。

# ε = ±1%, ±2% の候補を生成
paths = generate_candidates(base_atoms,
    strain_values=[-0.02, -0.01, 0.01, 0.02],
    output_dir="candidates/")
# → candidates/strain_-0.0200/POSCAR, ... (4ファイル)

7. フェーズ6: 最適化アルゴリズム（遺伝的アルゴリズム）

USPEXの核心である「探索」を実装。指示書の「遺伝的アルゴリズム（GA）」の基本を構築しました。

7.1 設計思想

最適化器は物理モデルに依存しない汎用設計です。候補（Candidate）は任意のパラメータ辞書であり、 評価関数は候補をスカラーフィットネス値にマッピングする任意の callable です。

7.2 評価関数

energy_fitness(result_dict) → float

デフォルトの評価関数。E/atom が低いほどフィットネス良好（最小化問題）。

weighted_fitness(result_dict, weights) → float

多目的最適化用の重み付き評価。エネルギー、体積、力などの複数目的関数を 重み付き線形結合として扱う。

7.3 遺伝的アルゴリズム (GeneticAlgorithm クラス)

操作手法詳細
初期化一様ランダムパラメータ範囲内で一様サンプリング
選択トーナメント選択2個体をランダム抽出し、フィットネスの良い方を選択
交叉BLX-αα=0.5 で親の範囲を拡張した一様分布からサンプリング
突然変異ガウス摂動σ = パラメータ範囲の 10%。突然変異率は設定ファイルで制御
エリート保存上位 10%各世代の上位個体を次世代に直接引き継ぎ
BLX-α 交叉:
d = |p1 − p2|,   child ∈ U[min(p1,p2) − α·d, max(p1,p2) + α·d] 
# 使用例：二次関数の最小値探索
from t2vasp.optimizer import GeneticAlgorithm, GAConfig

def quadratic(params):
    return sum(v**2 for v in params.values())

config = GAConfig(
    param_bounds={"x": (-5, 5), "y": (-5, 5)},
    population_size=30,
    num_generations=50,
)
ga = GeneticAlgorithm(config, quadratic)
best = ga.run()
print(f"Best: x={best.params['x']:.4f}, y={best.params['y']:.4f}, fitness={best.fitness:.6f}")

8. ヤーン・テラー効果と結晶場安定化エネルギー（CFSE）

指示書の「t2に関する具体的な物理理論」として、八面体結晶場理論に基づく t2g/eg 軌道分裂解析を実装しました。ヤーン・テラー（Jahn-Teller）効果は、 縮退電子基底状態を持つ分子・イオンが幾何学的歪みによって安定化する現象であり、 遷移金属酸化物や合金の構造・電子物性の理解に不可欠です。

8.1 理論的背景

結晶場分裂 (Crystal Field Splitting)

八面体配位場中で5つの d 軌道は2群に分裂します：

  • t2g (低エネルギー): dxy, dxz, dyz — 配位子方向を避ける軌道
  • eg (高エネルギー): dz², dx²-y² — 配位子方向を向く軌道

分裂エネルギー Δoct (= 10Dq) はバンド中心の差として定量化されます。

Δoct = E(eg center) − E(t2g center)

projected DOS から各軌道のバンド中心（重み付き平均エネルギー）を求め、その差を Δoct とします。

結晶場安定化エネルギー (CFSE)

d 電子が結晶場中で選択的に低エネルギー軌道を占有することによる安定化エネルギー：

CFSE = n(t2g) × (−0.4Δoct) + n(eg) × (+0.6Δoct) + npairs × P

ここで n(t2g), n(eg) は各軌道群の電子数、P は電子対エネルギーです。 等方場（分裂なし）では各 d 軌道が等エネルギーとなり、CFSE = 0 です。

高スピン（HS）と低スピン（LS）で電子配置が異なるため、d4–d7 では CFSEの値が変わります。これを d0–d10 の完全テーブルとして実装しました。

ヤーン・テラー効果 (Jahn-Teller Effect)

ヤーン・テラーの定理：「空間的に縮退した電子基底状態を持つ非線形分子は、 その縮退を解く幾何学的歪みを受ける」(Jahn & Teller, 1937)

八面体錯体においてJT効果が顕著に現れるのは、eg 軌道の占有が不均等な場合です：

  • 強い JT 効果（eg 不均等占有）: d4(HS), d7(LS), d9
  • 弱い JT 効果（t2g 不均等占有）: d1, d2, d4(LS), d5(LS), d6(HS), d7(HS)

典型例：Cu2+ (d9) の [Cu(OH2)6]2+ では、 軸方向の Cu-O 距離 (2.38 Å) が赤道面の Cu-O (1.95 Å) より長い正方伸長歪みを示します。

8.2 実装関数

compute_cfse(n_d_electrons, delta_oct, low_spin, pairing_energy)

d 電子数と Δoct から CFSE と JT 活性を計算。高スピン・低スピン両方のテーブルを内蔵。

# Cu²⁺ (d⁹) — 強 JT 活性
cfse_ev, cfse_delta, jt = compute_cfse(9, delta_oct=2.0)
# → cfse_ev=-1.2 eV, cfse_delta=-0.6, jt="strong"

# Cr³⁺ (d³) — JT 不活性
cfse_ev, cfse_delta, jt = compute_cfse(3, delta_oct=1.5)
# → cfse_ev=-1.8 eV, cfse_delta=-1.2, jt=None

compute_crystal_field(dos, cfg, n_d_electrons, low_spin, c_over_a)

projected DOS から結晶場パラメータ一式を抽出する統合関数：

  1. t2g / eg のバンド中心を重み付き積分で算出
  2. Δoct = eg 中心 − t2g 中心
  3. dz² と dx²-y² の個別中心から eg分裂（JT歪みの定量指標）を算出
  4. d 電子数が指定されていれば CFSE と JT 活性を計算
  5. c/a 比から正方歪みパラメータ |c/a − 1| を算出

compute_jahn_teller_energy(undistorted, distorted) → JahnTellerResult

高対称構造（未歪み）と低対称構造（歪み）の2つの計算結果から JT 安定化エネルギーを算出：

EJT = E(undistorted) − E(distorted) > 0 ⇒ 歪みが有利
JTSE/atom = EJT / Natoms
Δ(c/a) = |c/a(distorted) − c/a(undistorted)|

11. 設定ファイルと拡張性

すべての定数・係数は config/defaults.yaml に集約されています。 ユーザーは --config user.yaml でオーバーライド可能です。

# config/defaults.yaml (抜粋)

parser:
  structure_source: "CONTCAR"
  energy_tag: "free  energy   TOTEN"
  lattice_range: [1.5, 10.0]

calculator:
  reference_energies: {}        # 元素ごとの参照エネルギー (eV/atom)
  crystal_field:
    window: [-6.0, 4.0]         # フェルミ準位周りの解析窓 (eV)
    pairing_energy: 0.0         # 電子対エネルギー P (eV)
    low_spin: false             # 高スピン/低スピン切替
  elastic:
    strain_magnitudes: [-0.02, -0.01, 0.0, 0.01, 0.02]

pipeline:
  max_parallel_jobs: 4
  poll_interval: 30
  vasp_command: "mpirun -np 4 vasp_std"

optimizer:
  population_size: 20
  num_generations: 50
  mutation_rate: 0.15
  crossover_rate: 0.7
  elite_fraction: 0.1
  seed: 42

拡張ポイント

  • reference_energies にDFT計算した元素単体のエネルギーを追加 → 形成エネルギー自動計算
  • crystal_field.n_d_electrons を元素ごとに設定 → CFSE/JT の自動判定
  • crystal_field.pairing_energy を実験値/計算値に設定 → より精密な CFSE
  • optimizer パラメータのチューニング → GA の収束速度・探索精度の調整
