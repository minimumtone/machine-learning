解説書・テストレポート

概要

本ツールは、高エントロピー合金（HEA）の格子定数を、DFT計算に基づく構造特異的体積サイズ因子モデル（DFT-SSモデル）により予測する単一HTMLファイルのWebアプリケーションです。サーバー不要で、ブラウザのみで動作します（オフライン可）。

基本操作

  1. 結晶構造の選択: BCC または FCC を選択します。構造に応じて異なるΩsfデータ（B2→BCC, L12→FCC）と校正定数γが使用されます。
  2. 組成の入力: プリセットを使うか、ドロップダウンから元素を選択して原子分率（at%）を入力し「追加」をクリックします。「等モル追加」で全元素を等比率に設定できます。
  3. 正規化: 合計が100%でない場合、「正規化 (100%)」ボタンで比率を維持したまま100%に調整します。
  4. 予測実行: 「格子定数を予測」ボタンをクリックします。合計が100%でなくても内部で正規化されます。

出力の読み方

  • DFT-SSモデル予測: Ωsf補正を含む予測格子定数（Å）
  • Vegard則: 線形混合則による格子定数（Å）。Ωsf補正なし
  • γs: 構造依存の校正定数（BCC: 1.4517, FCC: 1.0824）
  • Vegardからの補正: γs × Σ cicjVjΩsf の値（Å³/atom）
  • 元素対Ωsfの詳細（折りたたみ）: 各元素ペアのΩsf値と体積寄与
  • Vegard縮退警告: Ωsfデータが欠損するペアがある場合に表示。該当ペアは補正なし（Vegard則に縮退）

制限事項

  • 本モデルはHEA単相固溶体を前提としています。秩序金属間化合物（NiAlなど）への直接適用は想定外です。
  • 全ての元素ペアにΩsfデータがあるわけではありません。データ欠損ペアはVegard則に縮退します。
  • B2ペア: 152対、L12ペア: 95対が収録済みです。

数学的背景

Alonsoらは、高エントロピー合金の単位胞体積を、体積サイズ因子（volume size factor）を用いて次式で表した:

Vuc = Z Σi ciVi + Z Σi ciVi Σj≠i cj Ωsf, j/i

ここで:

  • Vuc: 単位胞体積
  • Z: 単位胞中の原子数（BCC=2, FCC=4）
  • ci: 成分 i の濃度（原子分率）
  • Vi: 純元素 i の原子体積（Kingの原子体積）
  • Ωsf, j/i: 元素 j を元素 i の母相に溶かしたときの体積サイズ因子

第1項は各成分の平均原子体積に基づくVegard則型の寄与（線形混合則）、第2項は混合に伴う体積変化を表す補正項です。

DFT-SSモデルの拡張

本ツールで使用するDFT-SSモデルは、Alonsoモデルを以下のように拡張しています:

1. DFT計算によるΩsfの取得

Alonsoが実験値から取得したΩsfを、第一原理（DFT）計算の結果に置換しています。これによりデータカバレッジが大幅に拡大しました。データソースはMaterials Project (MP)、OQMD、自前のVASP計算です。

2. 構造特異的分離

Alonsoモデルでは全構造共通のΩsfを使用していましたが、本モデルでは:

  • BCC予測 → B2構造（秩序BCC）から導出したΩsf(B2)を使用
  • FCC予測 → L12構造（秩序FCC）から導出したΩsf(L1₂)を使用

配位環境の違いが原子体積に影響することを反映しています。

3. 校正定数γs

補正項にスケーリング定数γsを乗じます:

Vuc = Z [ Σ ciVi + γs · Σi Σj≠i cicjVj Ωsf(s)(i,j) ]

γFCC ≈ 1.08 はL12→FCC対応が良好であることを示します。γBCC = 1.45 はB2秩序構造とBCCランダム固溶体の構造差を反映する校正定数です。

4. 格子定数の算出

a = (Vuc)1/3 = (Z · v̄)1/3

ここで v̄ = ΣciVi + γs × 補正項 は平均原子体積です。

加法分解

247個の元素対パラメータ（Ωsf）を39個の元素固有パラメータδ(s)に圧縮できることが示されています:

Ωsf(i,j) ≈ δ(s)i + δ(s)j

δ(s)はHume-Rothery原子半径と同様の元素固有属性で、DFT体積から構造効果を内包する記述子です。

Vegard縮退

特定の元素ペアでΩsfデータが欠損している場合、そのペアの補正項は0になり、Vegard則に縮退します。NbMoTaWのように全6ペア（Nb-Mo, Nb-Ta, Nb-W, Mo-Ta, Mo-W, Ta-W）のB2データが欠損している場合、予測値はVegard則と完全に一致します。

Ωsfデータソース

体積サイズ因子は以下のデータベースから取得しています:

  • Materials Project (MP): DFT計算による安定構造データ
  • OQMD: Open Quantum Materials Database
  • VASP: 自前の第一原理計算（Table 6補完用）

各元素ペアで2件以上のデータが存在する場合のみΩsfを採用しています（min_count=2）。
