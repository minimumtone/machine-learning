# 変分法と密度汎関数法(DFT)教育アプリ

## 概要

このアプリケーションは、**変分法(Calculus of Variations)**の基本原理を学び、**密度汎関数法(DFT: Density Functional Theory)**による第一原理計算への応用を理解するための教育ツールです。

物理学および計算化学・材料科学における重要な概念を、インタラクティブな可視化とシミュレーションを通じて体験的に学ぶことができます。

## 機能

このアプリは5つのタブで構成されています:

### 📚 変分法の基礎
- 変分法の理論的基礎
- 汎関数とオイラー-ラグランジュ方程式
- 物理学における変分原理(古典力学、量子力学、DFT)

### 🎯 変分原理の実演
- 最速降下曲線問題(Brachistochrone Problem)のデモンストレーション
- 様々な曲線(直線、放物線、サイクロイド等)の比較
- 変分法による最適解の導出

### ⚛️ DFT基礎
- Hohenberg-Kohn定理の解説
- Kohn-Sham方程式の導入
- 交換相関汎関数の近似手法(LDA, GGA, Hybrid)

### 🔬 簡易DFT計算
- 1次元量子井戸のKohn-Sham方程式を数値的に解く
- パラメータ調整可能:
  - 電子数
  - 井戸の幅
  - 外部ポテンシャルの強度
- 可視化:
  - 外部ポテンシャル
  - 固有状態(波動関数)
  - 電子密度
  - エネルギー準位

### 📊 エネルギー最小化
- ガウス型試行波動関数による変分計算
- 3種類のポテンシャル:
  - 調和振動子(解析解あり)
  - 二重井戸
  - 非対称井戸
- パラメータ最適化の可視化

## 使い方

### アプリの起動

```bash
streamlit run variational_dft_app.py
```

ブラウザが自動的に開き、アプリケーションが表示されます。
デフォルトではhttp://localhost:8501でアクセスできます。

### 基本操作

1. **タブの切り替え**: 画面上部の5つのタブから学習したいトピックを選択
2. **パラメータ調整**: スライダーやセレクトボックスでパラメータを変更
3. **結果の確認**: リアルタイムで更新されるグラフと計算結果を確認

## 学習の流れ

推奨される学習順序:

1. **変分法の基礎** - 理論的背景を理解
2. **変分原理の実演** - 具体的な例で変分法の威力を体感
3. **DFT基礎** - 量子力学からDFTへの発展を学ぶ
4. **簡易DFT計算** - 実際の計算で電子構造を理解
5. **エネルギー最小化** - 変分法の実践的応用を体験

## 技術的詳細

### 数値計算手法

- **固有値問題**: NumPyの`linalg.eigh`を使用
- **有限差分法**: 2次中心差分による離散化
- **数値積分**: 台形則(`numpy.trapz`)による期待値計算

### 物理定数

アプリ内で使用されている物理定数(SI単位系):
- プランク定数: ℏ = 1.054571817×10⁻³⁴ J·s
- 電子質量: m_e = 9.1093837015×10⁻³¹ kg
- 電子ボルト: 1 eV = 1.602176634×10⁻¹⁹ J
