# 4ケース比較レポート: MP/OQMD $\times$ B2/L1$_2$

## 1. 概要

Materials Project (MP) および OQMD から B2 (CsCl型) と L1$_2$ (AuCu$_3$型) の二元系化合物を抽出し、有効原子半径を Trust Region Reflective (TRF) 最適化により算出した。$E_{\mathrm{hull}}$ フィルタは適用せず、全安定性レベルの化合物を対象とした。

### 適用フィルタ

| フィルタ | 内容 | 目的 |
|:---|:---|:---|
| 格子定数範囲 | 2.0 A $\leq a \leq$ 8.0 A | 超格子構造の除外 (例: Rh$_{17}$S$_{15}$, Pd$_{17}$Se$_{15}$) |
| 非金属元素除外 | H, He, C, N, O, F, P, S, Cl, Se, Br, Te, I 等 | 共有結合/イオン結合化合物の除外 (硬球モデル不適合) |

### 手法

- **B2 (CsCl型)**: $a_{\mathrm{calc}} = \frac{2}{\sqrt{3}}(r_A + r_B)$, 化学量論比 1:1
- **L1$_2$ (AuCu$_3$型)**: $a_{\mathrm{calc}} = \frac{2\sqrt{2}\,r_{\mathrm{major}} + \sqrt{2}(r_{\mathrm{major}} + r_{\mathrm{minor}})}{2} = \frac{\sqrt{2}(3r_{\mathrm{major}} + r_{\mathrm{minor}})}{2}$, 化学量論比 3:1
- **最適化**: scipy.optimize.least_squares (TRF法), Pauling半径を初期値として使用

## 3. 安定性分布

![安定性分布](https://app.devin.ai/attachments/0a7857cc-ac63-48d4-a35b-2a1eae39e29c/fig5_ehull_distributions.png)

**図5**: 各ケースの $E_{\mathrm{hull}}$ / stability 分布。赤破線は従来のフィルタ閾値 0.1 eV/atom を示す。

### 安定性分布の特徴

- **MP データ**: $E_{\mathrm{hull}}$ は 0 以上の値をとり、0 に近いほど熱力学的に安定。大部分の化合物が 0-1 eV/atom の範囲に分布。
- **OQMD データ**: `stability` は負値も取り得る (凸包上の化合物)。分布は MP と異なるが、全体的な傾向は類似。
- **フィルタなし**: $E_{\mathrm{hull}} < 0.1$ eV/atom のフィルタを適用しないことで、準安定・不安定化合物も含めた包括的な解析が可能。

## 6. 予測誤差と安定性の関係

![誤差 vs 安定性](https://app.devin.ai/attachments/3f09e01f-1859-4a58-8c7a-bd23d3f47bdf/fig6_error_vs_ehull.png)

**図6**: 各ケースの格子定数相対誤差 vs $E_{\mathrm{hull}}$ / stability。

**観察:**
- 全ケースにおいて、$E_{\mathrm{hull}}$ が大きい (不安定な) 化合物ほど誤差が大きくなる傾向がある。
- ただし、非金属除外後はこの傾向が大幅に緩和され、安定化合物 ($E_{\mathrm{hull}} \approx 0$) でも不安定化合物でも概ね同程度の精度が得られている。
- OQMD-L1$_2$ は全体的に誤差が小さく (最大 4.88%)、安定性に対する依存性も弱い。

## 7. 非金属除外の効果

非金属元素を含む化合物を除外する前後の精度比較:

| ケース | フィルタ前 RMSE (A) | フィルタ後 RMSE (A) | 改善率 |
|:---|:---:|:---:|:---:|
| MP — B2 | 0.1581 | **0.0520** | 67% 改善 |
| MP — L1$_2$ | 0.1838 | **0.1304** | 29% 改善 |
| OQMD — B2 | 0.1023 | **0.0895** | 13% 改善 |
| OQMD — L1$_2$ | 0.0638 | **0.0639** | (変化なし) |

MP-B2 で最も効果が大きく、RMSE が 67% 改善。これは IrN, OsN, TiO, CuO 等の強い共有結合/イオン結合性化合物が硬球モデルから大きく逸脱していたため。

## 8. 結論

1. **データ量**: OQMD は B2 構造で MP の約7倍のデータを提供する (2,539 vs 357)。L1$_2$ は MP の方が約3.6倍豊富 (848 vs 238)。研究目的に応じたデータソースの選択が重要。

2. **精度**: 非金属除外後、全ケースで平均相対誤差 2% 以下を達成。MP-B2 が最高精度 (0.99%)、OQMD-L1$_2$ が最小最大誤差 (4.88%)。

3. **半径の整合性**: B2 構造では MP/OQMD 間の半径は良好に一致 (RMSD = 0.045 A)。L1$_2$ では差が大きく (RMSD = 0.108 A)、特に希土類元素で顕著。

4. **硬球モデルの限界**: 非金属元素を含む化合物では硬球モデルが破綻する (誤差 20-30%)。金属間化合物に限定することでモデルの妥当性が大幅に向上。

5. **安定性の影響**: $E_{\mathrm{hull}}$ フィルタなしでも、非金属除外後は安定/不安定化合物間の精度差が小さい。不安定化合物を含めることでデータ量が増加し、より多くの元素の半径を推定可能。
