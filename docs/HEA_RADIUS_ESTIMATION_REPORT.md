- **エネルギー閾値**: energy_above_hull ≤ 0.1 eV/atom

- **B2構造 (AB)**: r_A + r_B = (√3/2) × a

## 8. 結論と推奨事項

### 8.1 主要な知見

1. **TRF最適化の有効性**: Pauling半径と比較して、B2で69.7%、L12で20.5%の精度向上
2. **B2外れ値の除外**: 非B2構造（Pd17Se15, Rh17S15）を除外することでB2 RMSEが0.37→0.04 Åに大幅改善
3. **ハロゲン除外が効果的**: L12構造でハロゲンを除外すると精度が約5%向上
4. **5元系サブセット計算**: 過決定系（n>5化合物）で平均RMSE=0.068 Å、約80%がRMSE<0.1 Å

### 8.2 HEA設計への推奨

1. **L12構造ベースの予測を優先**: より高い精度が期待できる
2. **遷移金属中心の組み合わせ**: アルカリ金属やハロゲンを含まない系で精度向上
3. **サブセット計算の活用**: 特定のHEA組成に対して、その元素のみを含む化合物データで半径を再計算することで精度向上が期待できる
