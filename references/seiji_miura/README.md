# 三浦誠司教授（北海道大学）論文収集

北海道大学 大学院工学研究院 材料科学部門 三浦誠司（Seiji Miura）教授の論文をOpenAlex APIから収集したもの。

## ファイル

| ファイル | 内容 |
|---|---|
| `miura_seiji_publications.md` | 年別の論文リスト（207件、1987–2026年） |
| `miura_seiji_publications.csv` | 論文メタデータ（タイトル・著者・誌名・巻号頁・DOI・被引用数・OpenAlex ID） |
| `miura_seiji.bib` | BibTeX形式 |
| `miura_seiji_excluded.csv` | 同姓同名の別人と判断し除外した112件（除外理由付き） |

## 収集方法

1. OpenAlex APIで "Seiji Miura" の著者プロファイルを検索（主ID: A5048323361、316件 + 北大所属の小規模プロファイル3件）
2. 各論文の三浦氏の所属（raw affiliation）を確認し、北海道大学（1999年以降）・東京工業大学（1987–1994年）所属を「本人確認済み」と判定
3. 所属情報のない論文は共著者ネットワークで判定：
   - 本人と判定: 三島良直・鈴木朝夫（東工大）、毛利哲夫・大久保賢二・池田賢一・柏谷悦章（北大）、C.T. Liu（ORNL）等との共著
   - 別人と判定: 橋本敏・三牧琢郎・中西典彦ら（京都大 三浦精氏の双結晶・形状記憶合金研究）、日立の三浦誓士氏（半導体）、北大地盤工学の三浦清一氏、建築・土木分野等
4. 判定理由は各CSVの `reason` 列に記載

## 注意

- OpenAlexの著者名寄せには誤りが含まれるため、除外/収録の判定は所属と共著者に基づくヒューリスティック。境界例は `miura_seiji_excluded.csv` を確認のこと
- researchmapやORCIDでの照合による精緻化が可能
