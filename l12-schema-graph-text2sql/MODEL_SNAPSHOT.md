# Model and run-time snapshot

This file records the model versions and run-time versions used to generate the
quantitative results in the paper.  These values are intended for reproducibility
reporting; re-running the evaluations with newer versions may produce different
outputs.

## LLM configuration

| Component | Model / version |
|-----------|-----------------|
| SQL generation | `gpt-5.5` (default, controlled by `LLM_MODEL`) |
| Repair loop | same as SQL generation |
| SQL/reranker candidate reranking | `gpt-5.5` (or `RERANK_MODEL` if set) |
| Schema table reranking | `gpt-5.5` (or `RERANK_MODEL` if set) |
| Japanese cross-encoder reranker baseline | `cross-encoder/ms-marco-MiniLM-L-6-v2` |

## Software versions used for the reported numbers

- Python 3.10.12 (original run); package default/validated: Python 3.12.13
- PostgreSQL 15 (official Docker image)
- psycopg 3.x
- MeCab 0.996 / ipadic 1.0
- networkx 3.x, sqlglot 20.x, openai 1.x
- matplotlib 3.x, numpy 1.x

## Result generation

- Date of the reported numbers: 2026-08-21
- `paper/paper_data.json` generated by `scripts/compute_all_figures.py`
- `paper/figures/*.pdf/png` generated by `scripts/generate_figures.py`
- Ablation 5-run statistics: `evaluation/ablation_multirun_stats.json`
- Per-query results (aggregates): `evaluation/ablation_run_*.json`
- Per-query generated SQL logs: `evaluation/generated_sql/{main,transfer,transfer_obfuscated,independent,prototype,cte,mp_transfer}/<qid>.sql` plus `manifest.json`

## External data snapshots

- Pure-element reference energies: OQMD data fetched by `scripts/fetch_oqmd_pure_elements.py`
- Materials Project transfer schema: built on-the-fly from the public MP REST API
  (`scripts/build_mp_transfer_db.py`)

## Notes

- LLM outputs are non-deterministic even with `temperature=0`; re-running the
  evaluation scripts will likely produce slightly different per-query accuracies.
- The main reproducible artifacts are therefore the database contents
  (`db/*.sql`), the evaluation queries/gold SQL/expected results
  (`evaluation/*.jsonl`, `evaluation/gold_sql/`, `evaluation/expected_results/`),
  and the aggregated numbers in `paper/paper_data.json`.

## Verified reproduction environments

- Default / validated environment: Python 3.12.13, PostgreSQL 15.18,
  numpy 2.2.1, sqlglot 30.12.0 (pinned in `requirements-repro.txt`;
  full freeze in `requirements-lock.txt`). `reproduce.sh` prefers
  `python3.12` when available (override with `L12_PYTHON`).
- Also verified: Python 3.10.12 (original reported-value generation) and an
  independent third-party reproduction on Python 3.12.3 / PostgreSQL 16.15 /
  numpy 2.5.2 / sqlglot 30.17.0 — `paper/paper_data.json` identical apart
  from the `_meta` block. PostgreSQL 15 or newer suffices.
