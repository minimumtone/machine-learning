4.2 Graph Structure

NetworkX DiGraph で構築される Schema Graph:

  • テーブルノード: material_entry, composition, structure, phase_stability, calculation, calculated_property, literature_reference
  • カラムノード: 各テーブルの全カラム (HAS_COLUMN エッジ)
  • FK エッジ: FOREIGN_KEY (双方向) — DB introspection で自動検出
  • JOINABLE_WITH エッジ: テーブル間の結合可能性 + join_on メタデータ

4.3 Traversal Algorithms

  • find_shortest_table_path(): 2テーブル間の最短パス (nx.shortest_path)
  • find_join_subgraph(): 複数テーブルを接続する Steiner tree 近似

例: 「Feを含む安定なL1$_2$化合物の格子定数」→ 必要テーブル: {composition, structure, phase_stability} → material_entry を中心に3テーブルを最短接続
