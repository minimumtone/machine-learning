# 独立評価用サンプルクエリ集（100件）

## 目的
本資料は、システム開発者以外の材料研究者が**自由記述で評価クエリを作成する**際の参考サンプルです。
以下のクエリはあくまで「こんな質問ができます」という例示であり、研究者ご自身の研究関心・日常的な疑問に基づいて自由に質問を記述してください。

## データベースの概要
- **対象**: L1₂型金属間化合物を中心とした第一原理計算データベース
- **規模**: 約1,471件（L1₂ 393件、B2 636件、NaCl 355件、NiAs 74件、BiF₃ 13件）
- **格納情報**: 組成・結晶構造・安定性・DFT計算条件・機械的性質・電子構造・磁性・熱特性・表面エネルギー・合金系分類・文献情報・合成条件・欠陥情報など

## 質問のルール
- **日本語の自然文で記述**してください（SQL知識は不要です）
- **1つの質問に複数の条件**を含めて構いません（例：「安定で、格子定数が3.5Å以上で、Niを含む化合物」）
- 回答不可能な質問（DB外の情報を要求するもの）を含めても構いません
- 質問の長さ・文体は自由です

## 記述のヒント

- **具体的な数値条件**があると検索しやすい（例：「3.5Å以上」「200GPa以上」「energy_above_hull < 0.01」）
- **複数テーブルにまたがる質問**も可能（例：「安定で、バルクモジュラスが高く、Niを含むL1₂」→ phase_stability + elastic_tensor + composition + structure を結合）
- **スコープ外の質問**（例：「この化合物の実験合成方法を提案して」「VASPの入力ファイルを作って」）はシステムが「回答不可」と判定します
- **曖昧な表現**も可能（例：「安定な」「硬い」「軽い」）→ システムがドメイン辞書で解釈を試みます

## 質問の記述フォーマット

以下の形式で記述してください：

```
番号. [質問文]
```

例：
```
1. Niを含む安定なL1₂型化合物の格子定数とバルクモジュラスを表示して。
2. データベースに登録されている化合物のうち、最も形成エネルギーが低いものは何か。
3. 強磁性を持つL1₂型化合物はあるか？あれば全て一覧にして。
```
