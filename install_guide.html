1. はじめに（このアプリについて）

このアプリは、ブラウザ上で動く対話的な教材です。 自分の PC にインストールして使います。インターネット接続はインストール時のみ必要で、 一度インストールすればオフラインでも動作します。

アプリでは以下のことが学べます：

  • 材料データの探索・可視化
  • 主成分分析（PCA）による次元削減
  • 回帰分析（線形回帰、SVR、ランダムフォレスト）
  • 分類（SVM、k-means）
  • 交差検証による汎化性能評価

2. 必要なもの

項目内容
パソコンWindows 10/11、macOS、または Linux
インターネットインストール時に必要（アプリ実行時は不要）
ディスク容量約 1 GB の空き
ブラウザChrome, Edge, Firefox など（既にインストール済みのものでOK）
プログラミングの経験は不要です。このガイドの手順をそのまま実行すれば動きます。

3. Step 1: Python のインストール

このアプリは Python（パイソン）というプログラミング言語で書かれています。 まず Python をインストールします。

Windows
macOS
1 Python 公式サイトを開く

ブラウザで以下の URL にアクセスしてください：

https://www.python.org/downloads/

2 「Download Python 3.xx.x」ボタンをクリック

ページ上部にある黄色い「Download Python 3.xx.x」ボタンをクリックします。

最も重要な操作：インストール画面の一番下にある 「Add python.exe to PATH」にチェックを入れてください。 これを忘れるとアプリが動きません。

チェックを入れたら「Install Now」をクリックしてください。

  3. 黒い画面が開いたら、以下を入力して Enter：
C:\Users\あなたの名前> python --version
Python 3.xx.x と表示されればインストール成功です。

4. Step 2: アプリのダウンロード

1 アプリファイルをダウンロード

以下の GitHub ページからアプリをダウンロードします：

https://github.com/minimumtone/machine-learning

  1. 緑色の「Code」ボタンをクリック
  2. 「Download ZIP」をクリック
  3. ダウンロードされた ZIP ファイルを好きな場所に展開（解凍）する
展開先は「デスクトップ」や「ドキュメント」など、わかりやすい場所がおすすめです。

5. Step 3: 必要なパッケージのインストール

アプリの動作に必要な追加ソフトウェア（ライブラリ）をインストールします。 「パッケージ」とは、Python に追加機能を提供するプログラムの集まりです。

1 コマンドプロンプト（ターミナル）を開く

Windows の場合：

  1. Windows キー を押して「cmd」と入力 → Enter

macOS の場合：

  1. Command + Space で「ターミナル」と検索 → Enter
2 アプリのフォルダに移動する

ダウンロードして展開したフォルダに移動します。

Windows の場合（デスクトップに展開した例）：

C:\Users\あなたの名前> cd Desktop\machine-learning-main

macOS の場合（デスクトップに展開した例）：

$ cd ~/Desktop/machine-learning-main
「cd」は「change directory（ディレクトリを変更）」の略で、フォルダを移動するコマンドです。
3 パッケージを一括インストール

以下のコマンドをコピー＆ペーストして Enter を押してください：

Windows の場合：

C:\...\machine-learning-main> pip install -r requirements.txt

macOS の場合：

$ pip3 install -r requirements.txt
requirements.txt はアプリに必要な全パッケージが記載されたファイルです。 このコマンドで一括インストールされます。
インストールには数分かかることがあります。画面にたくさんの文字が流れますが、 エラーが出なければ正常です。最後に「Successfully installed ...」と表示されれば成功です。
4 インストール確認

以下を入力して、エラーが出ないことを確認します：

Windows：

C:\...\machine-learning-main> python -c "import streamlit; print(streamlit.__version__)"

macOS：

$ python3 -c "import streamlit; print(streamlit.__version__)"
バージョン番号（例: 1.38.0）が表示されれば成功です。

6. Step 4: アプリの起動

1 アプリを起動するコマンドを実行

アプリのフォルダ内で、以下のコマンドを実行します：

Windows：

C:\...\machine-learning-main> streamlit run mi_textbook_app.py

macOS：

$ streamlit run mi_textbook_app.py
2 ブラウザが自動で開く

コマンド実行後、自動的にブラウザが開き、アプリが表示されます。

もし自動で開かない場合は、ブラウザのアドレスバーに以下を入力してください：

http://localhost:8501
ブラウザに「マテリアルズ・インフォマティクス (MI) とは」という画面が表示されれば成功です。
コマンドプロンプト（ターミナル）の画面は閉じないでください。 閉じるとアプリも停止します。アプリを使っている間は、その画面はそのまま放置してください。

7. Step 5: アプリの使い方

アプリの操作はすべてブラウザ上で行います。

画面の構成

場所機能
左側サイドバーセクション（章）の切り替え、データセットの選択
メイン画面理論の説明、数式、グラフ、操作パネル

基本操作

  • セクションの移動：左のサイドバーでセクション名をクリック
  • データセットの変更：サイドバーの「材料データ」ドロップダウンで選択
  • スライダー：パラメータ（正則化の強さ、次数など）を変更して結果の変化を観察
  • グラフの操作：マウスホバーで数値表示、ドラッグでズーム、ダブルクリックでリセット

推奨する学習順序

サイドバーの番号順（1 → 2 → ... → 8）に進めてください。各セクションは前のセクションの知識を前提としています。

8. Step 6: アプリの終了

1 コマンドプロンプト（ターミナル）で停止

アプリを起動したコマンドプロンプト（ターミナル）の画面で：

# キーボードで Ctrl キーを押しながら C を押す Ctrl + C

これでアプリが停止します。ブラウザの画面を閉じても OK です。

2 次回の起動方法

次にアプリを使いたいときは、Step 4 のコマンド（streamlit run mi_textbook_app.py）を 再度実行するだけで起動できます。パッケージの再インストールは不要です。

9. トラブルシューティング（困ったとき）

Q: 「python が見つかりません」「'python' is not recognized」と表示される
原因：Python インストール時に「Add python.exe to PATH」にチェックを入れなかった可能性があります。
対処法：Python を一度アンインストールし、再インストールしてください。 インストール時に必ず「Add python.exe to PATH」にチェックを入れてください。
Q: 「pip が見つかりません」と表示される
対処法（Windows）：pip の代わりに python -m pip を使ってみてください：
> python -m pip install -r requirements.txt
対処法（macOS）：pip3 を使ってください。
Q: 「ModuleNotFoundError: No module named 'streamlit'」と表示される
原因：パッケージのインストールが完了していません。
対処法：Step 3 のインストールコマンドを再度実行してください。
Q: 「Permission denied」「アクセスが拒否されました」と表示される
対処法（Windows）：コマンドプロンプトを「管理者として実行」してください。 スタートメニューで「cmd」と検索し、右クリック → 「管理者として実行」。
対処法（macOS）：コマンドの先頭に sudo を付けてください：
$ sudo pip3 install -r requirements.txt
パスワードを求められたら、Mac のログインパスワードを入力してください（入力中は画面に何も表示されません）。
Q: ブラウザに何も表示されない / 「このサイトにアクセスできません」と出る
対処法：
  1. コマンドプロンプト（ターミナル）が開いたままか確認する
  2. 画面に「You can now view your Streamlit app in your browser」と表示されているか確認する
  3. ブラウザのアドレスバーに http://localhost:8501 を直接入力する
Q: 「Address already in use（ポートが使用中）」と表示される
原因：前回のアプリが完全に終了していない可能性があります。
対処法：別のポート番号で起動できます：
> streamlit run mi_textbook_app.py --server.port 8502
ブラウザでは http://localhost:8502 にアクセスしてください。
Q: グラフが表示されない / 画面が白いまま
対処法：ブラウザのキャッシュをクリアしてページを再読み込みしてください （Ctrl + Shift + R または Command + Shift + R）。
Q: 上記で解決しない
エラーメッセージのスクリーンショットを撮って、担当教員に連絡してください。
