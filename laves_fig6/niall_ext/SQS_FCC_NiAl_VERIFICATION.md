# fcc Ni(Al) Al-rich データの SQS 検証まとめ

## 問い
Yamanouchi Fig. 6(a) 比較に使った fcc Ni(Al) 固溶体のデータ（特に x_Al ≥ 0.625）で、
2×2×2（32 原子）の乱数配置に大きなシードばらつきがあり、x=0.875 では 15.5–16.3 Å³/atom
と 0.8 Å³ も開いていた。このデータは信頼できるか？

## 検証内容
icet `generate_sqs_from_supercells` で **SQS 32 原子**（短距離秩序を意図的に打ち消した
fcc 理想ランダム固溶体）を全組成 0–1（ステップ 2/32）で生成・MLIP 緩和。
比較対象：
- 2×2×2 乱数配置 3 シード
- 既存 05_analysis/volumes.csv の fcc SQS データ（x ≤ 0.25）
- Vegard 則（fcc-Ni → fcc-Al）

## 主な結果

### 1. SQS は Vegard 線に近い
- SQS 体積は **Vegard 則に対しやや負の偏差**（x≈0.5 で最大 -1.23 Å³/atom）
  を示した後、x ≥ 0.75 でほぼ Vegard に復帰。
- x = 0.875 の SQS は **16.18 Å³/atom** で、Vegard 値（≈16.00）からはわずか +0.18。
  これは 2×2×2 乱数のうち **最大体積シード（16.33）** に近く、
  **小体積シード（15.50–15.63）より物理的に妥当**。

### 2. 2×2×2 乱数のばらつきは有限サイズ・局所秩序アーティファクト
- x = 0.875 で 3 シードのエネルギー/原子：
  - 15.50 Å³: -4.096 eV（高エネルギー）
  - 15.63 Å³: -4.104 eV（高エネルギー）
  - 16.33 Å³: **-4.159 eV**（最も低エネルギー）
- SQS（16.18 Å³）: **-4.137 eV/atom**
- つまり、x=0.875 の小体積シードは **高エネルギーの準安定配置**（孤立 Ni 配置など
  Ni–Al 結合を最大化しすぎて局所的に凝縮）で、**実際の fcc 固溶体体積は ~16.2**。

### 3. SQS もエネルギー的に必ずしも最安定ではない
- SQS の混合エネルギーは純元素基準で **全組成で負**（x=0.5 で -0.486 eV/atom）。
  → fcc 固溶体としては純元素分離に対して**熱力学的に安定**。
- しかし、2×2×2 乱数の中には SQS よりも低エネルギーの緩和構造が存在
  （例：x=0.625, 0.75, 0.875）。
  → これはfccランダム固溶体よりも **局所的な秩序・凝集（L1₂ 的な Ni 配置等）**
  を取った構造が、MLIP にはややさらに安定する可能性を示唆。
  すなわち、SQS/Vegard 線は **ランダム固溶体の参照線・補助線** として使うべきで、
  実際の低温平衡状態では秩序化や相分離が入る。

## 結論
- **純 Al 端点は正しい**（16.736 Å³/atom）。
- **Al-rich fcc Ni(Al) の SQS 体積は ~16.2 Å³/atom（x=0.875）で Vegard 線近傍**。
  2×2×2 乱数の 15.5 程度の小さい値は **準安定**。
- Fig. には **SQS / Vegard 線を補助線（緑三角＋黒実線）** として追加し、
  実データ（SQS や充分な大きさの cell）と区別して示すのが適切。
